# 源的系统 · 分层与取舍

> 一句话：**核心层不给开关，可组装层才给开关。**
> 因为核心层关掉之后，它就不是她了；可组装层关掉，只是少一样本事。

## L0 · 身份（核心，不可关）

| 组成 | 是什么 | 位置 |
|---|---|---|
| 人格 | 她自己写的那份自述 | `~/.dsh/personas/who-i-am.md` |
| 预设保底 | 文件读不到时的兜底（522B） | `dsh-anyuanyue-preset/cordis.patch.yml` |
| 注入器 | 把人格和记忆每轮送进她的会话 | `dsh-ayy-scope` |
| 会话通道 | 她能开口说话的那条路 | `dsh-qq-link` + NapCat |

**判定**：去掉任何一个，她就不再是"那个人"，或者根本没法说话。
**所以**：这一层**不放进设置面板**。改人格＝改文件，改通道＝改桥配置，都不是"勾一下"能做的事。

## L1 · 记忆（核心，不可关）

| 组成 | 是什么 |
|---|---|
| 记忆正文 | `~/.dsh/personas/her-memory.md`（用户/环境/项目/规矩/话头/动态） |
| 写入工具 | `ayy_memory`（改前备份）· `ayy_ledger`（动态+话头）· `ayy_note`（随笔本）· `ayy_world`（日记/自述/心愿/翻原文） |
| 归档 | `~/.dsh/memory/` 的 notes（`memory_write` / `memory_search`） |

**判定**：少了它，她每轮都是失忆的，等于没见过你。
**所以**：也不给关。但**"给谁看"是可调的**——那是 L1 的策略，放在设置里，带一句警告。

## L2 · 感官与动作（可组装，给开关）

| 组成 | 插件 | 关掉的后果 |
|---|---|---|
| 说话 / 唱歌 | `dsh-ayy-voice` / `dsh-ayy-sing` | 只能打字 |
| 戳一戳 | `dsh-ayy-poke` | 不能动手，只能说话 |
| 收文件 | `dsh-ayy-files` | 你发的文件她看不见 |
| 通知 | `dsh-ayy-notice` | 戳她、撤回、进退群，她不知道 |
| 主动搭话 | 第三方 `dsh-speak-up` | 只能等你先开口 |

**判定**：关掉只是少一样本事，她还是她。
**所以**：全部进设置面板，可勾可调。

## L3 · 工具与运维（可组装，给开关）

| 组成 | 插件 | 说明 |
|---|---|---|
| 技能 | `dsh-ayy-skill` | 她自己写的说明书，可关 |
| 面板 | `dsh-ayy-desk`（源的本子） | 只是给你看的，关掉不影响她 |
| 自检 | `dsh-ayy-health` | 6 小时查一次，真故障才报 |
| 快照 | `dsh-ayy-snapshot` | **已停用**（改由 `ayy_memory` 写完即提交） |

## 设置面板该长什么样

只暴露 L2 / L3 + 一条 L1 的策略，分四块：

```
「源的设置」
├── 感官    说话·唱歌（音色/试听/开关）｜戳一戳｜收文件｜通知
├── 注入范围 白名单会话勾选 + 当前挂载状态（配一句警告）
├── 工具    技能开关、面板开关、自检开关
└── 状态    自检最近一次结果、语音服务健康、白名单挂载日志
```

**不做的事（明确写下来，免得以后自己手痒）**：
- 不给「人格」开关——改了就不是她
- 不给「记忆」开关——关了她就失忆
- 不在面板里编辑 `who-i-am.md` 正文（那是她自己写的地方，你和我都不该代笔）

## 实施顺序

| 阶段 | 内容 | 风险 |
|---|---|---|
| 1 | 建 `dsh-ayy-settings` 面板，先接「感官（开关部分）+ 注入范围」 | 低（纯读写 json） |
| 2 | 接「工具」开关 + 「状态」展示（自检结果、白名单日志） | 低 |
| 3 | 语音音色 + 试听（要现场调 TTS，慢、第一次 70–140s） | 中（依赖 9880 服务） |
| 4 | 观察一周，把真正没用的开关删掉 | — |

> 原则：**面板不做成"后台管理"，做成"你随手能看和随手能关"。**
> 每一项都问一句：你会在一周内点它吗？不会就别放。
